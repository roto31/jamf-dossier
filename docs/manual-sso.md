# Manual SSO Documentation

Some SSO configuration is not fully exportable via Jamf Pro API.

## Manual capture

1. Jamf Pro → **Settings → System Settings → SSO**
2. Screenshot or export UI settings not present in API responses
3. Save captures under `captures/` in your backup folder
4. Document IdP metadata URLs, certificate expiry, and redirect URIs in operator runbook
