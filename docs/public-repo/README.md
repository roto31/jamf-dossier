# Public documentation repository

This folder describes the consumer-facing repo [**roto31/jamf-dossier**](https://github.com/roto31/jamf-dossier) (**Jamf Dossier**):

- Full user documentation, Mermaid diagrams, screenshots
- `CHANGELOG.md` and release metadata mirrors
- Signed `.dmg` on GitHub Releases (`Jamf Dossier-<version>-macos.dmg`)

**No Swift or Python application source** — use `scripts/sync_public_docs.sh` from the private monorepo.
